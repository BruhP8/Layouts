# We Were Here Too - Layouts

### **[LiveSplit](https://github.com/LiveSplit) layouts you can use.**
- The sole difference between the two files is the number of displayed splits as they differ according to the role.

### Layouts components:
- Game and run category details.
- Splits details (Name, Segment Time, PB Segment Delta, Time, PB Time Delta).
- Run and Segment Timer.
- Predicted time.
- Possible time save.
- Sum of best segments.
